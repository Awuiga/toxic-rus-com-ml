# Toxic Russian Comments — учебный проект

Подготовка русскоязычных комментариев для будущего классификатора токсичности на PyTorch. Сейчас реализована обработка данных, разбиение на выборки, словарь и DataLoader. `train.py` пока получает один батч и пропускает его через Embedding. **Обучение классификатора, метрики и предсказание токсичности ещё не реализованы.**

## Что уже работает

`prepare_data.py` ожидает локальный CSV со столбцами `comment` и `toxic`. Метки — 0 или 1. Скрипт удаляет пустые записи и точные дубликаты, приводит текст к нижнему регистру, нормализует пробелы и выделяет слова регулярным выражением.

Каждый класс отдельно делится на train/validation/test примерно 80/10/10 с seed 42. Словарь строится только по train, максимум 20 000 токенов и минимальная частота 2. `<PAD>` имеет ID 0, `<UNK>` — ID 1. Текст обрезается или дополняется до 64 токенов, размер батча — 32. Словарь сохраняется локально в `data/vocab.json`.

## Запуск

Проверялось на Windows с Python 3.13.2:

```powershell
git clone https://github.com/Awuiga/toxic-rus-com-ml.git
cd toxic-rus-com-ml
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Положите свой разрешённый к использованию `labeled.csv` в `data/`. Требования описаны в [data/README.md](data/README.md).

```powershell
python prepare_data.py
python train.py
```

Первая команда печатает размеры выборок, словаря и батча. Вторая выполняет текущий черновой шаг с Embedding, без цикла обучения. Для повторного вызова `build_loaders()` словарь строится и сохраняется заново.

## Ограничения и следующий шаг

Дедупликация оставляет первую метку для одинакового текста, отдельной обработки конфликтующих меток нет. Не реализованы поиск близких дубликатов, оценка баланса после очистки, модель классификации и оценка качества. Seed перемешивания данных задан, но инициализация Embedding не фиксирована.

Источник и лицензию имеющегося локального CSV по файлам проекта однозначно подтвердить не удалось. Поэтому ни корпус, ни полученный из него словарь не публикуются; неизвестные условия не заменены лицензией похожего датасета. Код принимает совместимый CSV, который пользователь получил правомерно.

Результаты проверки текущего состояния — в [VERIFICATION.md](VERIFICATION.md). При публикации исходная логика сохранена, добавлены описание и зависимости. Отдельная открытая лицензия на код пока не выбрана автором.
