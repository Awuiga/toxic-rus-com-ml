# Локальный CSV

Ожидаемое имя — `labeled.csv`, кодировка UTF-8, разделитель запятая, обязательные столбцы:

| Столбец | Содержимое |
| --- | --- |
| `comment` | Текст комментария |
| `toxic` | Метка 0 или 1 |

Используйте корпус с известным вам источником и подходящими условиями использования. Происхождение исходного локального файла не подтверждено, поэтому он не включён в Git, как и автоматически создаваемый `vocab.json`. Для повторения именно исходного эксперимента понадобится тот же файл; произвольный совместимый CSV даст другие размеры и словарь.
